# 📚 Flashcard Quiz App

> 🚧 **Project Status:** Under Development

A Flutter-based Flashcard Quiz App that helps users create, organize, and study flashcards in a simple and interactive way. The application is designed with a clean user interface and uses SQLite for offline data storage. This project is currently under active development, with new features and improvements being added regularly.

---

## 📖 About the Project

The Flashcard Quiz App is a mobile application built using Flutter that enables users to create custom flashcards for studying various topics. Users can add questions and answers, review flashcards one by one, and manage their study materials efficiently.

The primary goal of this project is to practice Flutter development, state management with Provider, and local database integration using SQLite while building a practical educational application.

---

## ✨ Current Features

- ✅ Add new flashcards
- ✅ View saved flashcards
- ✅ Show and hide answers
- ✅ Navigate through flashcards (Next & Previous)
- ✅ Delete flashcards
- ✅ Edit existing flashcards
- ✅ Offline data storage using SQLite
- ✅ State management using Provider
- ✅ Simple and clean Material Design interface

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (Latest Stable Version)
- Android Studio or VS Code
- Android Emulator or Physical Android Device

### Installation

1. Clone the repository

```bash
git clone https://github.com/birendrakalauni/flashcard_quiz_app.git
```

2. Navigate to the project directory

```bash
cd flashcard_quiz_app
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```

---

## 💾 Database

The application uses **SQLite** for local data storage.

**Database Name**

```text
flashcards.db
```

**Table Structure**

| Column | Type |
|--------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT |
| question | TEXT |
| answer | TEXT |
